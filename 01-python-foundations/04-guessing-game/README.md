# Higher-Lower Guessing Game

A number guessing game where the computer picks a random number (1–100) and you try to guess it within a limited number of chances. Guessing correctly resets the game with a new number, so you can keep playing.

## Features
- Random number generation
- Limited chances with feedback (higher/lower)
- Auto-restarts with a new number on a correct guess

## What I practiced
- Using Python's `random` module
- Loops with a counter (chances)
- Conditional comparisons

## How to run it
​```
python hl_game.py
​```
