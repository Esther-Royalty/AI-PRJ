# AI-eng# Budget Tracker (v1)

A command-line budget tracker that lets you log expenses and see your total spending.

## Features
- Add multiple expenses (amount + category) in one session
- View all logged expenses
- See total amount spent

## What I practiced
- Lists and dictionaries (storing structured data)
- Loops (`while` for repeated input, `for` to sum values)
- String handling (`.lower()` for flexible yes/no input)
- Accumulator pattern (running total)

## How to run it
​```
python budget_tracker.py
​```
