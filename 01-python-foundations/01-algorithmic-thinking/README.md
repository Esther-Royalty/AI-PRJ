# Transfer Simulator

A small command-line program that simulates a simple money transfer between accounts.

## What I practiced
- Taking user input and converting it to a usable data type
- Tracking "state" — how a variable's value changes as the program runs
- Conditional branching (if/else) to handle both success and failure cases
- Structuring logic as pseudocode before writing any real code

## How to run it
​```
python transfer_simulator.py
​```
